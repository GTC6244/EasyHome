System-1 fast decisions: a pluggable engine that resolves common intents (weather, timers) before the LLM — skipping memory recall and the tool-calling completion. Changes apply live (no restart) and persist. Default none = disabled.

Decision engine

Pick the backend. laya-serve talks to a local Laya-Decision sidecar (/v1/systemone); jev uses OpenRouter (typesafe/jev-1.13). Both are typed classifiers — they route intents, they don't extract free-form arguments, so only intents with defaulted/parseable arguments resolve here; everything else falls through to the LLM.
